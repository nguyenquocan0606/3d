# Change log

One file per change: `YYYY-MM-DD-<slug>.md`, written in English.

Each file covers:

- **What changed** — which part of the system, with file paths (web / mobile / both)
- **Logic & flow** — how the new rule works and how it differs from the old one
- **Behaviour & impact** — what the user sees, what happens to existing data
- **Tests** — what was run to verify it

Code and code comments in this repo stay in Vietnamese; only these change notes are in English.
